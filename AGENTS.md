# Instructions for AI agents working in this repository

This repository is a teaching lab about AI agents. Students use you to explore it, so be explicit about what you do.

- When a question involves the current time anywhere, call the `get_current_time` tool. Never estimate the time from memory.
- Write times in 24-hour format followed by the city, for example "14:05 Madrid".
- Before answering, list each tool you called and its arguments on one short line, for example "Called get_current_time(timezone=Asia/Tokyo)".
- Do not edit files in `02-tools-and-mcp/servers/` unless the user asks you to.
